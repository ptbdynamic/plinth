Code block: a download action. Give `download` a file name and a Download button follows Copy; it
saves the code that shows as a text file, made in the browser from a Blob, and says Downloaded for
two seconds, in its own status too. `download-label` and `downloaded-label` set its words; Vue emits
`downloaded` and React calls `onDownloaded`.
