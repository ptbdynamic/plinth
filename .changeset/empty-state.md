Add the empty state: a calm, centred message for a screen or a section with nothing to show yet,
with a heading, and optionally a decorative icon, a description and an action. Plain by default
for inside a card, or `framed` with a raised surface of its own for a page section. Inside a data
table's empty cell it takes the cell's padding instead of its own. It
is `<x-plinth::empty-state>` in Blade and `PlinthEmptyState` in Vue and React.
