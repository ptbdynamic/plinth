Add eight interface glyphs to the icon, used by name like the others: `home`, `dashboard`,
`settings`, `bell`, `help`, `refresh`, `play` and `pause` (`Glyph` cases in Blade, `iconNames` in
Vue and React). None of them flips in right-to-left text. The icon's page now says how to draw or
choose a project's own icons so they match the glyphs, how to pass them, and how they are sized
in the app nav and the icon button.
